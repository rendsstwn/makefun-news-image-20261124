Sum up the world's news of Tuesday 24 November 2026 in one image. The entry program writes a 1024x1024 PNG digest of 30 stories from that day: Jensen Huang returns as Nvidia CEO and shares surge 31%, a Russian drone enters Polish airspace overnight, Kyiv warns Russia is planning new strikes, the US sanctions Iran's shadow banking networks, Gaza students win their visa battle for Ireland, Sheikh Hasina plans her return to Bangladesh, Japan's factories expand, Congo halts cobalt exports, CrowdStrike buys Zscaler for $44bn, and 21 more stories from around the world. Sources: Reuters, AP, AFP, WSJ, Arab News, 24 Nov 2026.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.png` (1024x1024 PNG). The program copies `entry.png` from this repository, with no network, no randomness and no timestamps, so two runs write the same bytes.
